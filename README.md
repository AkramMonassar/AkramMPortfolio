# Akram Monassar — Professional Portfolio | بورتفوليو أكرم منصر
Bilingual (AR/EN) professional portfolio with dark/light themes, printable CV, and project gallery.

🔗 **Live Demo:** https://akrammportfolio.netlify.app

**Tech Stack:** HTML5 • CSS3 • Vanilla JavaScript • Font Awesome

**Features:**
- Full AR/EN switch with RTL/LTR support
- Dark / Light theme toggle
- Printable CV (PDF) in both languages
- Project image slider + fullscreen lightbox
- Working contact form (Web3Forms)
